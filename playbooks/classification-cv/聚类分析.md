# 方法卡：聚类 K-means / DBSCAN / GMM

- **方法名**：聚类分析（K-means/层次/DBSCAN/GMM/FCM）
- **所属原型**：classification-cv（无监督分组）
- **证据等级**：A（深卡）+ B（简卡 91 篇）
- **来源计数**：91 篇简卡（全语料第 2），多篇深卡

## 触发判据

- 无标签数据，要分组/分型/亚型。
- 特征空间自然簇结构。

## 输入与单位

- 标准化特征。
- K 用肘部/轮廓系数选。

## 建模骨架

1. 标准化。
2. 选算法：凸簇 K-means；任意形状 DBSCAN；概率软 GMM。
3. 选 K/eps/minPts。
4. 聚类结果解释+可视化。

## 算法菜单

| 算法 | 适用条件 | 参数来源 | 复杂度 | 常见失败 |
|---|---|---|---|---|
| K-means | 凸簇 | K 肘部 | O(nKt) | K 选错 |
| DBSCAN | 任意形状/噪声 | eps,minPts | O(n²) | 密度差 |
| GMM | 软分配 | 协方差 | 中 | 初始化 |
| 子空间聚类 | 高维多流形 | 见 2014 B | 高 | 高维 |

## baseline → 改进链

无分组 → K-means → DBSCAN/GMM → 子空间聚类。

## 验证套路

- 轮廓系数/CH 指数。
- 业务解释。

## 高分证据模块清单

- 子空间聚类处理多流形。
- 欠采样分层 + GMM。
- 层次聚类组批。

## 翻车点

- K 拍脑袋。
- 不标准化。
- 簇不可解释硬命名。

## 华为杯真题案例定位

- [2014-B-2014_B_B10248091_dc7ae638] 数据多流形：SSC 稀疏子空间聚类 + SMMC 改进相似度 + PID 参数调节 + 2DIMPCA 光照人脸识别。
- [2024-B-2024_B_B24103530099] WLAN 信号：DBSCAN + 双层级联预测 + 复合标签编码 + 深度残差网络。
- [2024-D-2024_D_D24104460003] 暴雨地理：欠采样分层 + GMM 聚类 + XGBoost。
- [2022-B-2022_B_B22100070171-p.19-21] 排样：杰拉德距离层次聚类组批。

## 相邻方法辨析

- vs 分类：聚类无标签，分类有标签。
- vs PCA：PCA 降维，聚类分组。
