# 原型四：classification-cv 分类与计算机视觉类

## 定义与触发判据

分类与 CV 类题目的核心是：**把对象/数据分到离散类别，或从图像/视频中检测、分割、识别目标**。题面通常出现"分类/识别/检测/分割/聚类/故障诊断/判别/区分"。

触发判据：
- 题面问"属于哪一类/是否异常/识别出目标"。
- 数据是带标签样本（分类）或图像/视频帧（CV）。
- 目标是离散类别或检测框/掩码。

## 建模骨架通用步骤

1. 明确类别定义与数据标签。
2. 特征提取（图像=CNN 特征/手工特征；表格=统计特征）。
3. 处理不平衡/小样本（SMOTE/欠采样/原型网络）。
4. 选分类器（SVM/树/集成/CNN）。
5. 评估：准确率/F1/ROC-AUC/混淆矩阵（分类）；mAP/IoU（检测分割）。
6. 改进：多基线对比 + 消融。

## 常见失败模式与避坑

- 不平衡数据准确率虚高（全猜多数类）。
- 不做 ROC/F1，只报准确率。
- CV 题不做数据增强/预训练。
- 聚类不选 K（肘部/轮廓系数）。
- 小样本直接上大模型过拟合。
