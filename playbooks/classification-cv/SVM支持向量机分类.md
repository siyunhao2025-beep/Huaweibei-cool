# 方法卡：SVM 支持向量机分类

- **方法名**：支持向量机（SVM）分类/核方法
- **所属原型**：classification-cv
- **证据等级**：A（深卡）+ B（简卡 46 篇）
- **来源计数**：46 篇简卡，多篇深卡

## 触发判据

- 中小样本、高维特征、类别可分。
- 要清晰决策边界。

## 输入与单位

- 输入：标准化特征向量。
- 必须标准化（核函数距离敏感）。

## 建模骨架

1. 特征标准化。
2. 选核（线性/RBF/多项式）。
3. 网格/PSO 调 C、γ。
4. 多分类用一对多/一对一。
5. ROC-AUC/F1 评估。

## 算法菜单

| 算法 | 适用条件 | 参数来源 | 复杂度 | 常见失败 |
|---|---|---|---|---|
| SVM-RBF | 非线性 | C,γ 网格 | O(n²) | 核选择 |
| 线性 SVM | 高维稀疏 | C | 低 | 欠拟合 |
| 半监督 SVM | 标注少 | 见 2018 C | 中 | 假设 |

## baseline → 改进链

逻辑回归 → SVM 线性 → SVM-RBF+PSO 调参 → 树模型对比。

## 验证套路

- 5 折交叉验证。
- ROC-AUC/F1/混淆矩阵。
- 与 RF/NN 对比。

## 高分证据模块清单

- SVM 核函数调优。
- SVM 前置清洗（云模型评估后）。
- 与 Bayes 组合。

## 翻车点

- 不标准化。
- 核函数选错。
- 只报准确率。

## 华为杯真题案例定位

- [2015-C-2015_C_C90110006_b2fe815e] 无线信道指纹：超分辨谱估计 + 变尺度分段 + SVM+Bayes 分类。
- [2024-B-2024_B_B24104760033] WLAN 吞吐：多模型对比 KNN/SVM/逻辑回归。
- [2021-C-2021_C_C21104240047] 帕金森：SVM 分类 + FPGA 仿真 DBS 靶点判别。
- [2018-C-2018_C_C18900450036] 恐袭：半监督 SVM。

## 相邻方法辨析

- vs RF：SVM 小样本高维优，RF 大样本抗噪。
- vs 神经网络：SVM 小样本稳，NN 大样本强。
