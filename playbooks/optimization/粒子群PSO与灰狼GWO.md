# 方法卡：粒子群 PSO 与灰狼 GWO

- **方法名**：粒子群优化（PSO）/ 灰狼优化（GWO）等群体智能
- **所属原型**：optimization
- **证据等级**：A（深卡支持）
- **来源计数**：PSO 30 篇简卡；GWO 多篇深卡（2022 C、2024 C）

## 触发判据

- 连续参数优化（调参/拟合系数/权重），目标可微但高维。
- 需要比 GA 更轻量的全局搜索，工程实现快。
- 常作为 ML 模型超参优化器（PSO-SVR、GWO-RF）。

## 输入与单位

- 粒子位置=待优化参数向量；速度=更新步长。
- 注意参数空间归一化（不同参数量级差大）。

## 建模骨架

1. 初始化粒子群位置/速度。
2. 每粒子评估适应度，更新个体最优 pbest、全局最优 gbest。
3. 速度更新 v = w·v + c1·r1·(pbest-x) + c2·r2·(gbest-x)。
4. 位置更新 x = x + v，加边界约束。
5. GWO 同理用α/β/δ 三头狼引导。

## 算法菜单

| 算法 | 适用条件 | 参数来源 | 复杂度 | 常见失败 |
|---|---|---|---|---|
| PSO | 连续参数 | w 0.4-0.9, c1=c2=2 | O(粒子×迭代) | 早熟/震荡 |
| GWO | 连续、鲁棒 | 收敛因子 a 线性降 | 同上 | 高维易陷局部 |
| PSO-GA 混合 | 精度要求高 | — | 略增 | 调参复杂 |
| PSO 调 ML 超参 | 模型调参 | 适应度=验证误差 | 较高 | 过拟合验证集 |

## baseline → 改进链

网格搜索/经验值（慢且粗）→ PSO/GWO 自动寻参 → PSO 调 ML 超参（PSO-SVR/GWO-RF）。

## 验证套路

- 与网格搜索/默认参数对比。
- 多次随机种子报最优值分布。
- 收敛曲线。

## 高分证据模块清单

- PSO/GWO 用于物理参数或 ML 超参，而非裸优化。
- 与树模型/神经网络结合（GWO-CatBoost、PSO-SVR）。
- 收敛+多次种子稳定性报告。

## 翻车点

- PSO 不做参数空间归一化，量级大的参数主导。
- 粒子飞出边界不做截断。
- 用 PSO 优化离散组合问题（不合适，用 GA）。

## 华为杯真题案例定位

- [2022-C-2022_C_C22103560098-p.21-23] 动态规划多目标 + 灰狼算法 GWO 解 PBS 调度，两数据集验证。
- [2024-C-2024_C_C24103860012] CatBoost 堆叠 + IGSE 物理 + GWO 灰狼优化磁芯损耗。
- [2024-C-2024_C_C24102890089-p.?] Steinmetz 修正 + ANOVA + PSO 多目标 + MLP/RF 集成。
- [2021-E-2021_E_E21103860006] UWB 定位 + PSO 寻优 + ELM 调优。
- [2014-D-2014_D_D10357002_b5f65f8a] PSO-GA 混合启发式。

## 相邻方法辨析

- vs GA：PSO 连续空间更自然，GA 组合排列更直接。
- vs SA：PSO 群体并行，SA 单解退火；PSO 快但易早熟，SA 逃逸局部更强。
