# 原型五：mechanism 机理建模类

## 定义与触发判据

机理建模类题目的核心是：**用物理/生物/工程的第一性原理（方程、定律、守恒）描述系统演化**，而非纯数据拟合。题面通常出现"机理/动力学/方程/传播/扩散/演化/系统随时间变化"。

触发判据：
- 题面要求"建立物理/生物/化学过程的数学模型"。
- 给了明确的守恒律/定律/过程机制。
- 要预测系统随时间/空间的演化，且解释成因。

## 建模骨架通用步骤

1. 识别系统要素与守恒/定律。
2. 写方程（ODE/PDE/代数）。
3. 简化假设（小量忽略/线性化）。
4. 解析解或数值积分（RK/欧拉）。
5. 验证：与物理公式/观测对比。
6. 稳定性/分岔/灵敏度分析。

## 常见失败模式与避坑

- 跳过机理直接黑箱拟合。
- 假设不写清楚。
- 数值积分不验证稳定性。
- 分岔分析看图说话不做统计检验。
- 2024 趋势：高分论文"物理公式打底 + ML 学残差"，纯机理或纯数据都不够。
