# 原型二：evaluation 评价决策类

## 定义与触发判据

评价决策类题目的核心是：**给定多个候选方案/对象和一组指标，综合打分、排序、选优或分类分级**。题面通常出现"评价/评估/排序/选优/指标体系/综合评判/权重/优劣"。

触发判据：
- 题面问"哪个方案更好/如何排序/建立评价体系"。
- 数据是多指标面板（指标×对象），需要确定权重并聚合。
- 指标有定性（模糊）或定量混合。
- 常与优化联用：先评价排序，再优化选点。

## 建模骨架通用步骤

1. 建立指标体系（目标层-准则层-指标层）。
2. 指标预处理：正向/负向标准化、无量纲化。
3. 定权重：主观（AHP）/客观（熵权/变异系数）/组合（AHP+熵权）。
4. 聚合：TOPSIS 相对接近度 / 模糊综合 / 灰色关联 / 云模型。
5. 排序 + 灵敏度（权重扰动稳健性）。

## 常见失败模式与避坑

- **权重拍脑袋**：只用 AHP 主观权重，不做一致性检验、不做熵权客观对照。
- **指标方向不统一**：正向/负向指标没统一，加权结果失真。
- **只排序不给灵敏度**：换权重排序是否稳？
- **指标堆砌**：指标间高度相关（未做 PCA/相关过滤），重复赋权。
- **2024 趋势**：纯熵权/TOPSIS 单独已降温（S4：2022→2024 从 4 次降到 0），需配树模型/物理机理。
