# 方法卡：TOPSIS 与改进 TOPSIS

- **方法名**：TOPSIS（逼近理想解排序法）/ 改进 RS-TOPSIS
- **所属原型**：evaluation
- **证据等级**：A（深卡支持）
- **来源计数**：多篇深卡，简卡高频

## 触发判据

- 多方案排序，要算各方案到正/负理想解的距离。
- 与熵权法联用是评价题"标配"。

## 输入与单位

- 输入：加权标准化矩阵。
- 单位：已标准化无量纲。

## 建模骨架

1. 标准化 + 加权矩阵 Z。
2. 正理想解 Z+（各指标最优）、负理想解 Z-。
3. 算各方案到 Z+、Z- 的距离 D+、D-。
4. 相对接近度 C = D-/(D+ + D-)。
5. 按 C 降序排序。

## 算法菜单

| 算法 | 适用条件 | 参数来源 | 复杂度 | 常见失败 |
|---|---|---|---|---|
| 经典 TOPSIS | 通用排序 | 权重 | 低 | 距离敏感 |
| RS-TOPSIS | 鲁棒/区间 | 见 2018 C | 中 | 区间设定 |
| 熵权-TOPSIS | 客观排序 | 熵权 | 低 | 标准组合 |

## baseline → 改进链

加权求和排序（粗）→ TOPSIS 相对接近度 → RS-TOPSIS 鲁棒/区间。

## 验证套路

- 与加权和/灰色关联结果对比。
- 权重扰动排序稳定性。

## 高分证据模块清单

- 熵权-TOPSIS 标准组合。
- RS-TOPSIS 处理不确定/区间数据。
- 排序带灵敏度。

## 翻车点

- 正负理想解算错（负向指标方向反）。
- 距离用欧氏不考虑指标相关。
- 不做权重扰动。

## 华为杯真题案例定位

- [2018-C-2018_C_C18900450036] 恐袭数据量化：RS-TOPSIS 改进 TOPSIS + 半监督 SVM + SIR 扩散 + RBF 时序 + 离群点检测。
- [2022-E-2022_E_E22103350038] 草原放牧：熵权-TOPSIS 类评价 + 多目标优化。

## 相邻方法辨析

- vs 灰色关联：TOPSIS 算距离，灰色关联算相似度曲线；两者常联用。
- vs 模糊综合：TOPSIS 用于定量排序，模糊综合用于定性定级。
