# 方法卡：熵权法客观赋权

- **方法名**：熵权法（Entropy Weight Method, EWM）
- **所属原型**：evaluation
- **证据等级**：A（深卡支持）
- **来源计数**：多篇深卡（2022 E、2024 D），简卡高频

## 触发判据

- 各指标数据差异可反映重要性（差异越大越重要）。
- 要客观赋权，不引入主观偏好。
- 与 TOPSIS/AHP 联用。

## 输入与单位

- 输入：指标×对象矩阵。
- 注意：先标准化，处理 0 值（取 log 前加小数）。

## 建模骨架

1. 标准化矩阵 P_ij。
2. 计算第 j 指标熵 e_j = -k·∑ p_ij ln p_ij。
3. 差异系数 g_j = 1 - e_j。
4. 权重 w_j = g_j / ∑ g_j。
5. 加权得分。

## 算法菜单

| 算法 | 适用条件 | 参数来源 | 复杂度 | 常见失败 |
|---|---|---|---|---|
| 熵权法 | 客观赋权 | k=1/ln n | 低 | 0 值处理 |
| 变异系数法 | 近似 | std/mean | 低 | 量纲敏感 |
| 熵权+TOPSIS | 排序 | — | 低 | 顺序僵化 |

## baseline → 改进链

等权 → 熵权客观赋权 → 熵权+TOPSIS 排序 → 熵权三层次体系。

## 验证套路

- 与 AHP 主观权重对比。
- 权重灵敏度。
- 排序稳定性。

## 高分证据模块清单

- 三层次脆弱性体系（目标-准则-指标）。
- 熵权与树模型/物理机理结合。
- 与 TOPSIS 联用给排序。

## 翻车点

- 0 值直接进 log。
- 指标未标准化就算熵。
- 把熵权当唯一依据不做灵敏度。

## 相邻方法辨析

- vs AHP：熵权客观、AHP 主观。组合最优。
- vs TOPSIS：熵权定权重，TOPSIS 算相对接近度，两者联用。
