# 原型三：prediction 预测类

## 定义与触发判据

预测类题目的核心是：**根据历史/当前数据，外推未来未知量或估计未知量**。题面通常出现"预测/预报/估计/推断/趋势/未来/外推"。

触发判据：
- 题面问"未来 X 时刻的值/下一阶段的量/某事件是否发生"。
- 数据是时序（按时间排序）或带标签的回归样本。
- 目标是连续值（回归）或事件概率。

## 建模骨架通用步骤

1. 明确预测目标与时域（短期/长期）。
2. 数据探索：趋势/季节性/噪声/异常。
3. 特征工程：滞后项/滚动统计/外部变量。
4. 选模型：统计时序（ARIMA）→ 树模型（RF/XGB）→ 深度时序（LSTM/GRU）→ 时空（GCN/ConvLSTM）。
5. 验证：训练/测试切分、滚动起点、多基线对比、分维误差。
6. 改进：残差建模/组合预测/物理约束。

## 常见失败模式与避坑

- **未来信息泄露**：用了未来数据做特征。
- **单一模型不对比**：S4 强调 2023 起"横向对比 5-11 种模型选优"成标配。
- **时序不切分**：随机切分导致未来泄露。
- **不做分维误差**：单一 RMSE 掩盖季节/区域差异。
- **纯黑箱不解释**：2024 偏好"物理机理打底+ML 学残差"。
