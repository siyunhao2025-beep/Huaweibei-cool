# 2026 华为杯正式提交论文模板

本目录的默认入口是 example.tex。它依据用户提供的第二十三届官方 Word 文件校正，详细依据见 docs/OFFICIAL_FORMAT_2026.md。

## 官方版式已落实

- A4；页边距：上 30 mm、下 17.5 mm、左/右 22.5 mm。
- 物理第 1 页为官方参赛信息封皮，作为逻辑第 0 页但不显示页码；物理第 2 页完整包含匿名题目、摘要和 3--6 个关键词，论文页码从 1 开始，物理第 3 页直接进入正文。
- 完整摘要后的下一页直接开始正文，**不生成目录**。
- 无页眉；学校、队号和队员姓名只出现在封皮，封皮后的摘要与正文匿名。
- 题目三号黑体，一级标题四号黑体居中，其他汉字小四宋体，单倍行距。
- 前置标签“题目/摘要/关键词”按官方 Word 模板使用隶书 18 pt。
- 官方 Word 模板的 ASCII/HAnsi 样式使用 Times New Roman；模板将排版文本中的英文、阿拉伯数字和西文标点统一为 Times New Roman。Overleaf 没有该微软字体时自动回退为 TeX Gyre Termes；公式使用 TeX Gyre Termes Math。按用户内部裁决，代码环境中的西文也使用 Times New Roman/TeX Gyre Termes，同时保留逐行结构、缩进和换行；不得改用 Courier 等字体。
- 摘要使用 `\textbf{...}` 选择性突出主要模型、决定性数值（连同单位）和核心结论/创新点；普通数字不机械加粗，禁止整句或整段加粗。
- 参考文献使用 `\clearpage` 另起一页；存在附录时，参考文献结束后再次 `\clearpage`，再执行 `\appendix`。这是用户确认的生产排版规则，不用于制造空白页。
- 计算型论文的附录必须包含代码式伪代码，并以“步骤—实际脚本/函数—结果文件”闭环；完整源码留在复现包。`章节模板/附录模板.tex` 只保留生成期注释，不预置可能被误当成真实算法的通用假代码；源码审计会拒绝缺失代码环境、占位符和无输入—计算—验证—输出语义的代码块。

## 用户确认的正文规则（非官方明文）

- 每份正式论文必须有一张“主要符号说明”三线表，默认放在基本假设或总体问题分析之后、第一问推导与全文首个模型公式之前。已核对的官方文件没有把这项单列为硬性条款，因此只能称为本 skill 的内部生产规则。
- 总表只收跨小问复用或理解全文必需的核心符号；局部参数在首次出现的公式附近定义。表前正文必须通过 `\ref` 引用，表本身须有 `\caption` 和唯一 `\label`，并按适用情况列单位或取值域。
- 三线表在同一表内使用 `\toprule`、`\midrule`、`\bottomrule`，不得带竖线、`\hline`、`\cline` 或网格线；不得使用 `\resizebox`、`\scalebox` 或缩小正文字号挤压。普通表优先 `tabularx`，确需跨页才改用 `longtable`。
- 默认入口已经给出与后续示例模型一致的三行最小符号表；新论文可从 `章节模板/符号说明模板.tex` 复制结构，但必须将“待替换”占位项换成本题真实符号并反查正文一致性，否则审计不通过。
- 多问题赛题先从 `章节模板/任务映射与总体分析模板.tex` 锁定各问的输入/硬约束、数学任务、输出/成功条件和真实依赖，再选择模型。该骨架按真实问题数增删；没有共享接口或统一验证边界时删除总体分析与共享数据小节，不为形式完整保留空壳。

## Figure 锁定与用户篇幅裁决（核对至 2026-09-21）

- 当届官方材料只明确摘要篇幅**一般不超过两页**；没有给出正文最低页数、正文上限或全文总页数上限。本模板另按用户内部规则把题目、完整摘要和关键词固定在一个逻辑页；题目优先一行、必要时最多两行且宽度均衡，不靠空话、缩字号或压行距填挤页面。
- 正式出图前先向用户展示逐图清单与建议总数；用户回复“锁定 N 张”或“图片总数：XX”后才锁定。计数对象是论文中带图号的顶层 Figure，复合图子面板不另计；最终 visual plan 与 LaTeX 必须精确一致。
- Figure 锁定后，按真实模型、推导、实验、图表与验证给出预计完整 PDF 页数区间，由用户回复“论文总页数：XX”或“论文长度：证据充分即可”。没有默认 50+ 目标。
- 用户要求增加 Figure 时必须增加独立证据；证据不足就报告缺口与可支撑上限。禁止套话、重复图表、无效模型、放大图表、强制分页和无关附录。
- 若赛题 PDF、竞赛系统或后续官方通知另行给出明确限制，以更新且更具体的要求为准，并在最终 PDF 上执行上限审计。
- 正常章节收尾留白可以保留；应修复多余分页、浮动体失控或排版错误造成的异常大面积空白，不得缩小官方字号、行距或页边距来挤页。

## 两个入口

- `example.tex`：2026 正式提交默认入口，包含第 0 页封皮，随后从匿名摘要第 1 页开始。
- `example-with-identity-cover.tex`：保留的显式命名兼容入口，版式与 `example.tex` 相同。

## Word 派生边界

仓库不再捆绑名为“研赛论文Word标准模板”的旧 v2.1 社区稿；它含目录、占位正文和错误页边距，不能冒充第二十三届官方附件 3。需要可编辑 Word 时，用 `build_docx.py --template <本地有权使用的.docx>` 生成派生稿，再运行 `audit_docx.py`。派生成功只证明结构审计通过，不等于该输入模板自动取得官方或再分发资格；正式提交仍以最终 PDF 为准。

实名封面的虚线竖框和页面四角标记是 Word 编辑界面的表格网格线/裁切标记，不属于打印版式，因此 LaTeX PDF 不输出这些辅助线。四个徽标资源来自用户提供的第二十三届官方 Word 模板。

## Overleaf 使用

1. 上传 `example.tex`、`gmcmthesis.cls`、`gmcm-title.sty`、`gmcm.bst` 和四个 `figures/identity-*` 徽标文件；将 `example.tex` 重命名为 `main.tex`（或设为主文件）。
2. 在 Menu → Compiler 选择 XeLaTeX。
3. 填写 `\schoolname`、`\baominghao`、`\membera`、`\memberb`、`\memberc`；再替换题目、摘要、关键词和正文，不添加目录。
4. 编译两遍，确认物理第 1 页封皮不显示页码；物理第 2 页显示页码 1，并完整容纳题目、摘要和关键词；物理第 3 页直接进入正文；封皮之外没有身份信息。

公开仓库不提供预打包 Overleaf ZIP。请只从你已获授权的本地资产组装项目：以正式提交入口复制为 `main.tex`，并按需加入 `章节模板/` 与 `华为杯_论文章节规范.md`；这些辅助文件不会被 `main.tex` 自动载入。公开再分发前先核对 `docs/UPSTREAM.md` 的第三方许可状态。

竞赛系统只接收编译后的单个 PDF，不接收 Overleaf ZIP、TeX 源文件或单独的封皮图片。最终 PDF 按“题号字母+队伍编号”命名，并在提交 MD5 后保持文件不变。

标题字体优先使用 Windows 的华文新魏；Overleaf 缺少该字体时，gmcm-title.sty 会自动采用 TeX Live 自带的中文回退字体，仅影响三行赛事标题，不会替换正文宋体。西文字体的合法回退规则见上文；不要把 Times New Roman 字体文件打包上传或提交到仓库。

## 生成器与审计

\`audit_tex.py\` 的 \`--manifest\` 应传入原始 TeX-only 清单（例如 \`论文输入.json\`），而不是生成后的 \`main.inputs.json\`；后者仅用于追溯本次生成时实际写入的输入文件。原始清单顶层必须显式包含 `appendix_pseudocode`：计算型稿件设 `{"required": true}` 且声明附录，纯解析题才可设 `false` 并给出具体理由；缺失裁决不得默认放行。

scripts/build_latex.py 从 TeX-only manifest 生成带正式封皮结构的主文件，并在参考文献、附录入口前写入 `\clearpage`；scripts/audit_tex.py 检查输入顺序、主要符号三线表、独立起页、附录可追溯伪代码、无目录、封皮后匿名、页式和格式覆盖，并拒绝摘要内直接压缩排版或改写版心。普通源审计允许脚手架暂留空封皮，但正式提交前必须增加 `--require-filled-cover`；`submission_audit.py --cover-policy required` 也会拒绝空字段和占位值。scripts/visual_plan_audit.py 核对用户锁定 Figure 总数与最终 LaTeX；scripts/audit_paper.py 以编译结果核对题目—摘要—关键词单页、题目 1--2 行及平衡度、摘要/关键词字号、正文从下一页开始、Times 系西文字体和用户篇幅裁决；scripts/build_docx.py 与 scripts/audit_docx.py 提供可选 Word 派生链，保留符号表题注与三线边框，并核对相应标题的段前分页。最终版式仍须以 PDF 逐页视觉检查为准。

交付前固定做三轮：源码/测试审计 → XeLaTeX 编译并逐页看图 → 解压本地最终 Overleaf 包后重新编译与复审。三轮都通过才算模板验收完成；本地交付包不自动取得公开再分发许可。
