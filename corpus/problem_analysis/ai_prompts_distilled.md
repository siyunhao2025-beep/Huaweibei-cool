## 一、可用 AI 辅助提示词模板（按阶段）

### 阶段 0：前置信息（每次对话先给）

```
我是参加数学建模竞赛的选手，需解决题目：【粘贴完整题目文本及附件说明】
团队情况：□ 零编程基础 □ 擅长 Python/MATLAB □ 有基础建模经验 □ 首次参赛
需求重点：□ 模型创新性 □ 代码可执行性 □ 结果可视化 □ 论文写作素材
获奖目标：□ 国一 □ 国二 □ 国三
```

### 阶段 1：题目分析

```
请逐句解析题目，用表格分列「背景信息 / 核心问题 / 已知条件 / 约束条件」。
明确小问划分：共几问，各小问「直接目标」与「隐含目标」。
用思维导图展示各小问关联与参数依赖。
题型分类：每小问属 □优化(单/多目标) □预测(时序/回归) □评价(指标体系) □机理分析 □其他，并说明依据。
```

### 阶段 2：模型选择

```
针对每小问推荐 2 种模型：
方案1（基础适配）：经典模型组合创新（如 AHP+熵权法+TOPSIS 评价、GA+BP 预测）。
方案2（创新融合）：跨领域深度模型组合（如 GNN+强化学习做路径/资源分配、GAN+CNN 做预测/评价）。
每种模型说明：核心原理（通俗语言）、适配性（为何适合本题）、创新点、局限性、可视化流程图（含决策分支）。
```

### 阶段 3：数据处理

```
题目数据如下【上传附件/列出】。
预处理：
- 缺失值：选 均值/插值/KNN 填充并说明依据（时序用线性插值）。
- 异常值：Z-score/IQR 检测，说明保留/修正/删除理由，附箱线图。
- 转换：是否需标准化/归一化（SVM 必需），给公式。
- 数据补充：区分「必须补充」与「可选补充」，给获取途径（统计局/Kaggle），并基于合理假设生成补充数据。
```

### 阶段 4：模型建立

```
结合方案2与处理后数据，详述每小问建模步骤：模型准备、变量定义（表：决策/中间/目标变量，类型/单位/范围）、公式推导、假设条件（3-5 条，含合理性与影响说明）、建模流程图。
```

### 阶段 5：模型求解与代码

```
对每问编写可运行代码求解：
数据输入→参数初始化→模型调用→结果输出，标注注意事项（如 α∈[0,1] 需调试）。
零编程基础：提供可直接运行代码，标注依赖库与安装命令（pip install numpy），关键行注释「为何这么写」，含结果可视化模块。
输出代码运行结果，结果要体现对题目的求解。
```

### 阶段 6：结果分析

```
对每问求解结果做基础分析+深层分析：
基础：数值解读（物理意义）、统计描述（均值/方差/极值）。
深层：关联性（是否满足约束）、敏感性（关键参数 ±10% 结果变化）、实际意义（结合背景）。
最后整理成表：每问核心问题 / 模型 / 答案 / 检验情况。
```

### 阶段 7：模型检验

```
有效性检验：按模型类型选指标（预测用 RMSE，评价用 Kappa 一致性），给检验代码（5 折交叉验证）与结果。
改进方向：误差大时（增数据/非线性项/集成）；假设不合理时（放松假设+随机扰动）。
鲁棒性：加 10% 噪声观察结果变化幅度。
```

## 二、论文写作 AI 提示词

### 初稿撰写（按模块）

```
目标：拿一等奖。基于已完成的各问分析/建模/求解/检验，生成论文。
1. 题目：「基于 XXX 模型的 XXX 问题研究」。
   摘要：问题-方法-结果-结论结构，800-1000 字，≤1 页，无图表，含具体数据/误差。
   关键词：3-5 个（含核心模型名+主题词）。
2. 问题重述：原创语言，禁抄原题，提炼 2-3 子问题，引 1-2 篇近 3-5 年文献。
   问题分析：总-分结构，每问「关键矛盾→思路框架→步骤拆解」，≤1 页。
   模型假设：3-5 条，每条含①内容②合理性依据③对模型影响。
   符号说明：三线表（符号/含义/单位）。
3. 各小问模型建立与求解：
   模型原理+步骤+核心公式（含推导逻辑）；
   求解工具（MATLAB/sklearn）+步骤+关键结果；
   结果分析（基础+深层+直接回应问题）；
   模型检验（残差/显著性，如灰色预测后验差比 C/P 判定精度等级）。
4. 模型评价：优点 3-5 条（创新/适用/效率，带数据），缺点 2-3 条（假设限制/数据依赖/可扩展性）。
   参考文献：5-10 条近 5 年，期刊[J]+专著[M]，中外结合，优先核心期刊。
   附录：完整代码（标注语言/版本/注释）+中间结果+清洗后数据+补充图表。
```

### 摘要专项优化（二次）

```
对摘要做二次优化：
- 篇幅 800-1000 字、≤1 页（A4 宋体小四）。
- 要素：背景→问题→方法→结果→结论；数据模糊表述改具体值（"结果较好"→"准确率 91.3%"）。
- 术语精准："神经网络"→"BP 神经网络"；标注创新点并量化（"求解速度提升 30%"）。
- 格式：每段以「针对问题 X」开头，含该问内容/方法/结果（如 Pareto 解、利用率 92%）。
```

### 终稿校对

```
对论文初稿系统优化：
- 文字校对：错别字、"的/得/地"、句子残缺。
- 逻辑梳理：补逻辑断层，章节衔接（问题分析提出的思路在模型建立中落实）。
- 格式规范：字体字号、图表编号（图 1-1）、公式编号（式 2.3）、三线表、符号一致。
- 内容精炼：删冗余、补参数物理意义。
输出终稿。
```

## 三、三天冲刺时间分配（经验值，扫描件待核）

> 原 `三天极限速成教程.pdf` 为扫描件，正文不可机读。以下为通用研赛节奏**经验值**，供参考，非原文。

- **Day 1（选题+建模）**：上午读题/选题/查文献；下午确定每问模型与数据预处理；晚上跑通第 1 问代码出图。
- **Day 2（求解+写作）**：上午完成第 2-3 问建模求解；下午写摘要+问题重述+模型假设+符号说明；晚上写模型建立与求解正文。
- **Day 3（检验+排版）**：上午模型检验/灵敏度/鲁棒性；下午补结果分析+模型评价+参考文献；晚上排版校对+摘要终稿+附录代码。

## 四、冲刺 Checklist

- [ ] 每问都有：模型名 + 公式 + 代码 + 结果图 + 检验指标
- [ ] 摘要 ≤1 页、800-1000 字、含具体数值
- [ ] 符号说明三线表、图表编号统一
- [ ] 参考文献 5-10 条近 5 年、格式规范
- [ ] 附录代码完整可复现
- [ ] 模型优缺点各 2-5 条、带数据支撑
- [ ] 灵敏度/鲁棒性分析齐全
