# 2025 年 C 题：围岩裂隙精准识别与三维模型重构

> 证据等级：**C（商业资料，仅供参考）**。来源：`C题完整模型建立与求解策略.docx`（2.4 万字）、W/L 老师思路 PDF。

## 一、题面主题与任务拆解

本题为**钻孔成像（Borehole Imaging）围岩裂隙的图像处理与三维重构**。从钻孔展开图识别裂隙、提取产状、计算粗糙度、三维连通。

- **第 1 问**：钻孔展开图裂隙**像素级二分类分割**——U-Net + BCE+Dice loss，Adam 优化。
- **第 2 问**：正弦状裂隙自动聚类（CCA 连通域分析）+ 正弦参数 (R,P,β,C) 非线性最小二乘拟合（L-M / curve_fit）。
- **第 3 问**：复杂裂隙轮廓线骨架化（Zhang-Suen 细化）+ JRC 粗糙度系数计算 + 自适应采样。
- **第 4 问**：多钻孔裂隙**三维连通性**（平面法向量/产状/距离/JRC 加权）+ 补充钻孔贪心优化（p-center 变种）。

## 二、数据模态与规模

- 钻孔展开图（图像）+ 多钻孔坐标/方位。
- 规模：图像分割数据集。

## 三、官方硬约束

- 裂隙产状（倾向/倾角）几何一致性；JRC 标定。

## 四、题型原型判断

**图像处理 + 深度学习分割 + 几何建模 + 优化**。依据：U-Net 分割、CCA、L-M 曲线拟合、Zhang-Suen 骨架、p-center 选址。

## 五、方法谱系

| 方法 | 频次 | 出处 |
|---|---|---|
| U-Net 语义分割 + BCE+Dice | 高 | C 题完整模型 |
| CCA 连通域分析 | 高 | C 题完整模型 |
| 非线性最小二乘（L-M/curve_fit） | 高 | C 题完整模型 |
| Zhang-Suen 骨架细化 | 中 | C 题完整模型 |
| JRC 粗糙度计算 | 中 | C 题完整模型 |
| 多钻孔三维连通 + 贪心选址 | 中 | C 题完整模型 |

## 六、推荐/备选路线

- 主流：U-Net 分割 → CCA 聚类正弦裂隙 → L-M 拟合规状 → 骨架化算 JRC → 三维连通 + 贪心补孔。
- 创新：Mask R-CNN/Transformer 分割；点云 3D 裂隙建模。

## 七、避坑点

- 分割用 BCE+Dice 联合 loss（裂隙细长，Dice 防类别不平衡）。
- 正弦参数拟合初值要合理，否则 L-M 不收敛。
- JRC 需标定采样长度。
