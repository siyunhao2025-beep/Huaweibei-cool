# docs/PEER_COMPARISON.md · 与 v2.1 工程包、Ku-academic 的对比

## 1. 与 v2.1 工程包（上游）

- **关系**：v2.1 是本仓库的上游主来源（见 `docs/UPSTREAM.md`）。论文模板、论文链脚本、视觉计划脚本、contest_init 均移植自 v2.1。
- **v2.1 有什么**：成熟的论文工程链（LaTeX/Word 构建审计）、求解/绘图规范、比赛初始化。
- **本仓库的增量**：
  1. **729 篇获奖论文蒸馏知识**：v2.1 没有大规模语料统计；本仓库有 729 简卡 + 80 深卡 + 方法频次统计。
  2. **8 原型 51 方法卡 + match_rules**：把"该用什么方法"变成可匹配的 playbook。
  3. **24 题赛道档案**：按年归档、跨届按原型聚类，强调"字母按届重置"。
  4. **国一模式提炼**：S3 数模之星摘要/创新点模式、S4 近三年升温降温清单。
  5. **内容级门禁脚本**：progress.py / review.py / submission_audit.py，比 v2.1 的工程审计多了"内容达标"判断。
- **不做什么**：不重写 v2.1 的论文构建链，直接复用。

## 2. 与 Ku-academic（风格参考）

- **关系**：仅借鉴其模块写法风格（目标声明→操作规则→清单→检验→边界），未复制其任何文件。
- **相同**：紧凑、任务契约式、清单化、边界明确。
- **不同**：
  - Ku-academic 是学术论文通用场景；本仓库是华为杯研赛专用，绑定 729 篇语料与官方规则。
  - 本仓库多了赛题原型匹配、赛道档案、MATLAB 工程规范、AI 披露等竞赛体裁内容。

## 3. 一句话定位

v2.1 给"怎么把论文做出来"的工程链；Ku-academic 给"模块怎么写得紧凑"的风格；本仓库在两者之上，叠加"729 篇获奖论文蒸馏出的方法论与选题/方法/创新知识"，解决"建模选什么、怎么写能拿高分"。
