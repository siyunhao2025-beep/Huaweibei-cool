# 读题审计报告（quickstart 玩具样例 · 桩内容）

> 这是一个**桩示例**，演示正式读题审计报告该长什么样。正式题请替换为真实读题结果。

## 1. 题目一句话
给定成本函数与固定售价，求使利润最大的产量，并做成本系数 ±10% 的鲁棒性分析。

## 2. 要素拆解
| 要素 | 取值/说明 |
|---|---|
| 决策变量 | 产量 x（连续） |
| 目标 | max P(x) = 50x − C(x) |
| 成本 | C(x) = a·x² − 10x + 100，标称 a=1 |
| 约束 | 无显式约束（x≥0，本题内部解自然满足） |
| 评价要求 | 成本系数 ±10% 下利润变化 |

## 3. 方法选型（粗筛）
- 解析法：P(x) = −(1+a?)... 见下，对 a=1 直接求导。
- 对 a=1：P(x) = −x² + 60x − 100，P′(x) = −2x + 60 = 0 → **x* = 30**，**P* = 800**。
- 鲁棒性：a ∈ {0.9, 1.0, 1.1}，P*(a) 与 x*(a) 见 problem.yaml 注释。

## 4. 风险与待确认
- 售价是否真的与产量无关（题目已固定，无需确认）。
- 本题为单变量凸优化，不需要整数规划/启发式。
