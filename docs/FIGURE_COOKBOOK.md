# docs/FIGURE_COOKBOOK.md · 数模图册烹饪手册

> **用途**：一张图该画什么型、配什么色、用多大字、怎么导出，本手册一页速查。
> 与 `skills/academic-figure/` 规范对齐：配色取其 CATEGORICAL 语义调色板、字号以 8 pt 为基准、导出"矢量 PDF + 300 dpi PNG"双份。
> 语料案例标注 `paper_id`，均来自深卡 `figure_narrative_order`。

---

## 0. 四条总则（先于一切图种）

1. **一图一结论**：一张图 3 秒看懂主结论。删去不传递信息的网格线、边框、图例项。
2. **语义色 > 任意色**：一张图内 2–4 个主色 + 1 个强调色；同一颜色在全文同一语义（蓝=基线/对照，红=最优/风险，绿=改进）。
3. **为黑白打印设计**：关键比较不能只靠红/绿区分，必须叠加线型/形状/直接标注。
4. **矢量优先**：折线/柱状/散点/流程出 PDF/SVG；只有热力色块、遥感影像类出 300 dpi 位图。

### 0.1 证据组合与数量审查

- “丰富”只表示证据角色覆盖充分，不表示图越多越好。简单/标准/复杂问题通常分别审查 2–3 / 3–5 / 4–7 个非冗余 Figure，并配 1–2 / 2–4 / 3–5 张三线表；低于范围写明替代证据，高于范围逐张证明信息增量。
- 四个标准/复杂问题的全篇审查范围通常为 15–25 个 Figure（含必要全局图）与 8–16 张表。范围是查漏提示，不是奖项公式，也不能压过题面和真实数据。
- 每问优先覆盖：机理/数据结构、主结果、独立验证或公平比较、灵敏度/鲁棒性/情景。相同数据换图型、把图中数值原样再列一表、把正文数字单独做空表，都属于重复证据。
- 表用于精确查值，图用于趋势、结构、分布和关系；同一实验同时进入图表时，两者 caption 必须说明不同用途。

## 2. 八原型必备图清单

> 按 `playbooks/INDEX.md` 八原型。每个原型标出"少了就不完整"的必备图（必做）和"加分图"（有就更好）。

### 2.1 optimization（约束下求极值）
- 必备：**收敛曲线**（多算法同图对比）、**灵敏度/参数扫描图**、**方案对比图**（本方案 vs 基线）。
- 加分：目标函数曲面/等值线（2D 投影）、Pareto 前沿（多目标）、求解时间对比表。
- 语料：收敛曲线 `2022_C_C22103560098`（GWO 收敛）；Pareto `2014_D_K0032_810b1655`；灵敏度 `2021_F_F21102480018`（ε 曲线）。

### 2.2 evaluation（多指标打分）
- 必备：**权重/指标分布图**、**排名雷达图**（多对象多维）、**敏感性分析**（权重扰动后排名稳不稳）。
- 加分：TOPSIS 得分柱状、AHP 一致性检验、熵权—突变点。
- 语料：政策评价雷达 `2011_D_D99999040_e74e768f`；权重雷达 `2021_D_D21103000002`（模型评估雷达）。

### 2.3 prediction（外推/回归）
- 必备：**拟合对比图**（实测 vs 预测同框）、**误差/残差分布图**、**滚动/外推预测曲线**。
- 加分：多模型偏差对比表、R²/MAPE 标注、置信带。
- 语料：预测拟合对比 `2009_X_1048611A_6d0da813`；滚动外推 `2024_D_D24106570027`（ARIMA/LSTM）。

### 2.4 classification-cv（分类/识别）
- 必备：**混淆矩阵**、**ROC/AUC**（二分类）、**特征分布图/重要性排序**。
- 加分：降维可视化（PCA/t-SNE 散点）、多分类器对比柱状、检测框示意。
- 语料：混淆矩阵 `2024_C_C24102890089`；ROC/AUC `2024_D_D24104460003`；PCA 碎石图 `2009_X_1048611A_6d0da813`。

### 2.5 mechanism（机理方程）
- 必备：**拟合曲线**（模型 vs 实测）、**残差分析图**、**机制/几何示意图**。
- 加分：分岔图/参数时变图、守恒量误差曲线。
- 语料：HH 放电时域 + ISI 分岔图 `2021_C_C21102920013`；受力拟合 `2024_A_A24102940057`。

### 2.6 signal（谱估计/滤波）
- 必备：**波形图**（时域）、**频谱图**、**滤波前后对比图**。
- 加分：时频图（STFT/HHT）、SNR/误差对比、超分辨谱峰标注。
- 语料：功率谱 SNR `2012_A_A90005004杨丁刘`；滤波前后 `2009_X_论文1042215B 最终`；CLEAN 谱估计 `2015_C_C90110006_b2fe815e`。

### 2.7 spatial-graph（空间/图/网络）
- 必备：**插值/热力图**（空间结果）、**拓扑/网络图**、**时空序列图**。
- 加分：Moran's I 显著性、路径/调度示意图、标准差椭圆。
- 语料：Kriging 插值 `2024_D_D24106570027`；区域网络图 `2007_X_邮政运输规划(1029301)`；淹没范围 `2008_X_9004521_93e4580c`。

### 2.8 simulation（随机仿真/排队）
- 必备：**置信区间/误差棒图**（多次重复）、**敏感性分析**、**蒙特卡洛收敛曲线**。
- 加分：分布直方图、场景对比矩阵、排队/流转示意。
- 语料：三采样法对比 `2024_F_F24103360083`；Monte Carlo recovery `MonteCarloRecovery/`；四情景 `2008_X_9004521_93e4580c`。

## 3. 配色规范

### 3.1 主调色板（与 academic-figure 一致，COPY 用）

```python
CATEGORICAL = ["#2166AC", "#B2182B", "#1B7837", "#F1A340", "#762A83", "#666666"]
DIVERGING   = ["#2166AC", "#F7F7F7", "#B2182B"]   # 正负/离差
SEQUENTIAL  = ["#F7FBFF", "#6BAED6", "#08306B"]     # 强度/频次
ACCENT_RED  = "#B2182B"   # 仅用于最优/风险/最强调，小面积
GREY        = "#999999"   # 背景/非显著/对照
```

### 3.2 语义角色

- 蓝 `#2166AC`：基线、对照、主参考。
- 红 `#B2182B`：最优结果/高风险方向，**小面积**使用，不大色块。
- 绿 `#1B7837`：改进/受益/另一组。
- 橙 `#F1A340`：第二对比（红已用时）。
- 紫 `#762A83`：第三/第四类、另一模型族。
- 灰 `#999999`：背景点、非显著项。

### 3.3 色盲友好（Okabe-Ito 备选）

红—绿同为关键比较时，Okabe-Ito 安全序：**橙 `#E69F00`、天蓝 `#56B4E9`、绿 `#009E73`、黄 `#F0E442`、蓝 `#0072B2`、朱红 `#D55E00`、紫红 `#CC79A7`**。对色觉障碍读者，**关键差异必须叠加线型（实/虚/点）或形状（圆/方/三角）**，不能只靠颜色。

### 3.4 黑白打印可区分

- 灰度下相邻色亮度差要大：避免"蓝 vs 紫"这种灰度相近的配对做关键比较。
- 灰度相近的两条线，用不同线型区分。
- 热力图用单色渐变（SEQUENTIAL）而非多色，黑白打印仍可辨强弱。

### 3.5 禁用

`jet` / `rainbow` / `hsv` / 默认 `tab10` / Excel 默认 / `Set1-3` 渐变彩虹图。这些"一看就没设计"。

## 4. 字号规范

> 以最终打印尺寸（不是屏幕尺寸）为准。基准 8 pt，**任何文字不小于 5 pt**。

| 元素 | 推荐字号 | 说明 |
|---|---|---|
| 面板内短标题 | 9 pt | 仅在多面板需要时使用；不重复论文图题 |
| 轴标签 | 8 pt | 含单位 |
| 刻度数字 | 6–7 pt | 最小不低于 5 pt |
| 图例文字 | 7–8 pt | 图例标题可 8 pt 加粗 |
| 图内标注/注释 | 7 pt | 直接标注优于长图例 |
| 多子图 (a)(b) 标号 | 8–9 pt 加粗 | 左上角 |

> 一行图内文字密度控制在"打印后仍清晰可读"；多子图时子图内部文字可降到 6 pt，但不低于 5 pt。中文字体走 academic-figure 中文闸门（`FontProperties` + `axes.unicode_minus=False`）。论文图题不画进图片，统一交给 LaTeX `\caption{}` 放在图下方，并服从官方小四宋体版式。

## 5. 导出规范

- **双份导出**：矢量 PDF（投稿主文件）+ 300 dpi PNG（预览/汇报）。
- 线图/柱状/散点/流程 → **PDF 矢量**（`pdf.fonttype=42` 嵌字体，文字不转轮廓）。
- 热力色块/频谱时频/地理栅格 → **PNG ≥300 dpi**；超高清点可 600 dpi。
- 超多散点（>10 万点）→ 数据层 `rasterized=True`，坐标轴与文字仍保持矢量。
- `savefig.bbox="tight"` 自动裁边；华为杯正文版心宽约 165 mm，按最终 `\linewidth` 设计画布（单图常用 0.72–1.00 `\linewidth`，双图各约 0.48 `\linewidth`），**不要套用 183 mm 双栏期刊宽度，也不要事后大幅缩放**。
- 图注位置：论文图题位于图下方；必要的数据来源/统计口径写入图题或紧随图题的说明。图片内部不重复大标题；图号、正文引用和文件内容一致。

```python
mpl.rcParams.update({
    "pdf.fonttype": 42, "svg.fonttype": "none",
    "savefig.bbox": "tight", "savefig.dpi": 300,
})
fig.savefig("fig_xxx.pdf", bbox_inches="tight", dpi=300)
fig.savefig("fig_xxx.png", bbox_inches="tight", dpi=300)
```

### 文件命名

`fig{题号}_{图种}_{内容}`，同名导出 `.pdf` 与 `.png`，如 `fig2_convergence_GWO.pdf/.png`、`fig4_roc_RF.pdf/.png`；与正文图号一致；补充图用 `figS1_...`。
