# 2004–2021 年赛道体系归档

> 本文件归档华为杯研赛 2004–2021 年（早于正式档案区间 2022–2025）的赛道体系。
> **红线：赛道字母按届重置，含义不跨届固定。** 早年多为 X（无赛道码），更不能把字母当定律。

## 一、赛道字母体系沿革

- **2004–2006**：基本无赛道字母（多数 track=X，从封面补题）。
- **2007–2012**：逐步出现字母（A–D 为主），但命名不规范。
- **2013 起**：稳定为 A–F 六题体系，沿用至今。
- **早年 X 处理**：2004–2008 大量论文 track=X（题面字母缺失），Wave1 按封面/题目归年。X 不等于任何字母。

## 三、已知数据质量问题

- **2014/2015 主题疑似串号**：2014 A 与 2015 A 标题重合（均含"水面舰艇编队防空"），2014 D/E 与 2015 D/F 标题也部分重合。推断为 Wave1 抽取时嵌套目录（2014 内含"2015年…"误标文件夹）导致。已在 AGGREGATE_STATS.md 标注，早年主题速查仅供方向参考，不作精确命题依据。
- **X 类**：2004–2008 多数无字母，主题从标题推断。
- **乱码论文**：部分早期 PDF 文本乱码（如 2017 C），标题提取失败。

## 四、早年论文奖级识别

- 全语料 729 篇中，奖级待确认 615 篇（84.4%）。早年（2004–2012）PDF 封面奖级信息尤其不规范，大部分无法可靠识别一/二/三等奖。
- 深卡（80 篇）集中在 2014 后，早年深卡稀疏，方法结论置信度低。
