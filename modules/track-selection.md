# modules/track-selection.md · 选题决策

> **目标**：多题选一时，用 `tracks/` 档案和 `track-selection-stats.md` 把"选哪题"从拍脑袋变成可比较的决策。**红线：赛道字母按届重置，含义不跨届固定。**

## 1. 红线先立

- A/B/C/D/E/F 只是当年题号，**不等于"A=优化、B=评价"**。例：2022 A 雷达信号、2023 A WLAN 信道、2024 A 风电功率分配——字母同，主题完全不同。
- 选题只看**当届题面内容**，不看字母历史。
- `tracks/` 按年建档（每题一份），`track-selection-stats.md` 做跨届**按原型**聚类，不是按字母。

## 2. 决策四问（依次过）

1. **队伍背景匹配**：你们最强的方法栈是哪类？信号？优化？ML？看图选最对口的原型。
2. **数据量与成熟度**：数据量大、方法成熟的题上手快（语料经验：2023 E 脑卒中、2024 D 暴雨类）；专门技术门槛高但撞车少（2022 A 雷达、2024 F 脉冲星类）。
3. **方法储备匹配**：跑 `scripts/playbook_match.py` 看推荐原型的方法卡你们是否做过。
4. **风险评估**：是否需要你们不熟的专门领域知识（如相对论天体物理、雷达超分辨）？时间够不够补？

## 3. 用 tracks 档案做比较

对每道候选题读 `tracks/{年}/{字母}.md`，记四列：

| 维度 | 看什么 |
|---|---|
| 题面内容 | 这题到底在问什么（不是字母） |
| 方法谱系 | 往届同类题用什么主方法 |
| 数据模态/规模 | 结构化/时序/图像/信号，量级 |
| 证据等级 | A=深卡支持 / B=简卡支持 / C=商业思路 |

> 2024 年每题仅 4 篇获奖论文样本，单题结论置信度低，别过度解读。

## 4. 跨届题型速查（按内容，不按字母）

摘自 `track-selection-stats.md`：

- 信号/雷达型：2022 A、2024 F、2025 E。
- 优化调度型：2022 B/C/D、2023 C、2024 A。
- 预测/时序型：2022 E、2023 D/F、2024 A/B/D。
- 评价决策型：2022 F、2023 C、2024 D。
- 图像/CV 型：2024 E、2025 C/F。

## 5. 选题 Checklist（D1 中午前必须打满）

- [ ] 读过每道候选题的题面，能一句话复述它在问什么。
- [ ] 跑完 `playbook_match.py`，主原型明确。
- [ ] 每道候选题的数据可下载、可打开、规模可处理。
- [ ] 选定题的主方法栈你们至少做过 baseline。
- [ ] 有"Plan B 题"，若 D1 晚 baseline 跑不通可切换。
- [ ] 选题理由写成 3 行：为什么选、风险是什么、Plan B 是什么。

## 6. 趋势提醒（来自 S4，非定律）

- 纯遗传/纯熵权/纯 ARIMA 单独拿奖已降温；2024 高分偏好"物理机理打底 + ML 学残差 + 消融/对标"。
- 历史获奖论文的篇幅与实验量增加，只能说明应预留写作和验证时间；样本为获奖论文条件样本，不能推出“写得越长越容易获奖”，也不能据此凑页。

## 7. 边界

- 以上是语料观察（单年事件不升级为定律），不是当届题情；当届题面永远优先。
- 选题一旦定了，不要在 D2 后再换（沉没成本 + 时间不够）。
