# modules/solving.md · 求解主线

> **目标**：从读题到出结果的求解流水线——读题→假设→建模→算法选型→编码→结果，每一步有"做到什么程度才算过"。
> 上游来源：提炼自 v2.1 `华为杯_求解规范/华为杯_求解规范.md`（63KB），非原样复制；原文位置见 `docs/UPSTREAM.md`。方法卡来自 `playbooks/`。

## 0. 硬门禁（不可覆盖）

- 题意有歧义 → 停，不猜。
- 无基线不进主模型。
- 结果不可复现不算完成。
- 原始数据只读，不直接改。

## 1. 读题

1. **问题结构**：几问、各问直接目标与隐含目标、问间依赖。
2. **数据与附件清单**：每张表的行列/缺失/量纲/规模；多文件对齐键。
3. **硬约束单独摘出**：单位、取值范围、禁止项、必须输出的格式（见 `kickoff-audit.md`）。
4. **连续/离散分清**，量纲与参考系统一。

> 题面约束 > 模型复杂度。题面禁止机器学习时不要硬上；"不建议"时要给不用的理由。

## 2. 假设

- 列 **≥3 条**假设，每条三要素：**内容—合理性依据—对模型的影响**。
- 不写"此假设不影响结果"这种空话；写不清影响的假设就别加。
- 假设要服务于简化，不是凑数。

## 3. 建模：基线—主模型—改进

- **基线**：最简可用模型（一个能跑通、能出数的东西），证明问题可解。
- **主模型**：针对题面特征选的核心模型。
- **改进**：针对主模型的短板做针对性升级（"上一步哪里不好→为什么换"）。
- 每一步写清"为什么换"，形成因果链，不要并列堆算法。

### 方法选型决策树（结合 playbooks）

```
题面→playbook_match.py 判主原型
├─ optimization？ → 有明确评分公式/可线性化？
│   ├─ 是 → 精确求解器（MILP/intlinprog/Gurobi）做基线与验证
│   └─ 否/规模大 → 启发式（GA/PSO/SA/NSGA-II）+ 局部搜索精修
├─ evaluation？ → 定权方式：客观(熵权/PCA) / 主观(AHP) / 组合(AHP+熵权)
│   └─ 排序：TOPSIS / 灰色关联 / 模糊综合
├─ prediction？ → 数据量与外推步长
│   ├─ 小样本 → 灰色GM(1,1)/Weibull/线性回归
│   ├─ 时序 → ARIMA 基线 + LSTM/树模型提升（组合）
│   └─ 表格数据 → 树模型(RF/XGBoost) 基线 + 对比
├─ classification-cv？ → 监督分类 / 聚类 / 图像(CV)
├─ mechanism？ → 机理方程(ODE/传染病/HH) + 参数辨识
├─ signal？ → FFT/滤波/超分辨(MUSIC/DOA)/小波去噪
├─ spatial-graph？ → 路径/网络流/VRP/GIS空间插值
└─ simulation？ → 蒙特卡洛/排队论/离散事件/多智能体
```

> 2024 高分范式：**物理机理打底 + ML 学残差 + 消融/对标**（见 `corpus/cards/S4_recent_trends.md`）。

## 4. 12 类题型建模要求（提炼自 v2.1 §8）

| 题型 | 建模要点 |
|---|---|
| 描述统计/因素分析 | 分布刻画 + 相关/因素分解，别一上来回归 |
| 分类 | 特征工程 + 评估(混淆矩阵/AUC)，不平衡先处理 |
| 回归/预测 | 基线→对比→集成，报误差不是只报R² |
| 机理/参数辨识 | 方程有据 + 参数可辨识 + 与数据拟合 |
| 优化 | 变量/目标/约束三段写清，先精确后启发式 |
| 鲁棒/不确定性 | 场景/扰动集合 + 最差情形求解 |
| 图像分割/CV | 检测/分割模型 + 评价指标，别只跑通 |
| 振动/时序信号 | 谱分析/滤波 + 特征 + 后续识别 |
| 图论/调度/排样 | 建模为图/整数规划，先小例后大规模 |
| 路径/几何/布局 | 几何约束 + 路径算法，画示意图 |
| 三维重构/连通网络 | 几何/坐标转换 + 网络连通性 |
| 多模态融合 | 统一数据表示 + 对齐，别硬拼 |

## 5. 编码与结果

- 固定随机种子；向量化优先；MATLAB 工程细节见 `matlab-conventions.md`。
- 结果结构化落盘（.mat/.csv/.json），不要只打印到控制台。
- 运行时间/复杂度记录：大规模题要给复杂度分析。
- 每出一个结果立刻问"怎么证明它对"，同步进 `validation.md` 流程。

## 6. 常见错误

- 套模型：不看数据特征直接上 LSTM/GA。星队共性是先做相关性/稀疏性/分岔分析再选算法。
- 并列堆算法而无"短板→改进"因果。
- 结果不落盘、不可复现。
- 单位/量纲没统一，最后对不上题面输出。
