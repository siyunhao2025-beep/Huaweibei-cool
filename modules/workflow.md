# modules/workflow.md · 比赛日全流程总览

> **目标**：拿到题面到提交的 72 小时里，知道每一小时该在哪一步、交什么、靠什么放行。本模块是"地图"，详细契约看 `phases.md`，脚本门禁看 `docs/PHASE_GATES.md`。

## 0. 总原则

- 研赛比赛窗口约 72 小时（以当届通知为准，本模块按 72h 排）。
- 节奏不是"一口气写完"，而是"选题—建模—求解—验证—成稿—打磨—提交"七段接力，每段有产物和门禁。
- **先跑通第一问、再求全**：Day1 末必须有一个能跑的 baseline，宁可三问都有雏形，不要一问精雕细琢。
- 官方题面与官方规则 > 本仓库任何经验值；当届通知覆盖一切默认。

## 1. 72 小时时间线

| 时段 | 主任务 | 产物 | 对应阶段 |
|---|---|---|---|
| D1 08:00–12:00 | 开赛审计：题面/规则/数据/环境 | 题面约束清单、数据完整性记录 | P0–P1 |
| D1 13:00–18:00 | 选题 + 题型判定 + 第一问建模 | 选题结论、原型匹配、第一问假设与模型链 | P1–P2 |
| D1 19:00–24:00 | 第一问 baseline 跑通、出第一张图 | 第一问结果、求解脚本、初图 | P2–P3 |
| D2 08:00–14:00 | 第二、三问建模+求解 | 各问结果、模型对比表 | P2–P3 |
| D2 14:00–20:00 | 验证主线（误差/对比/灵敏度） | 验证结果文件、消融/对标 | P3 |
| D2 20:00–24:00 | 论文初稿（问题重述/假设/建模/求解） | 初稿正文 60% | P4 |
| D3 08:00–12:00 | 摘要 + 结论 + 灵敏度/鲁棒性补全 | 摘要定稿、结论章 | P4–P5 |
| D3 13:00–17:00 | 打磨审校：图规范/引用/封皮后匿名化/数字一致 | 打磨版 | P5 |
| D3 17:00–20:00 | 提交审计 + 打包 + 上传 | 提交包、AI 披露 | P6 |

> 时间为**经验值**（源自 `corpus/problem_analysis/ai_prompts_distilled.md` 三天冲刺节奏），不是官方要求；按队伍熟练度前后浮动。

## 2. 阶段与产物交接（P0–P6）

| 阶段 | 名称 | 输入 | 必交产物 | 放行条件（内容级） |
|---|---|---|---|---|
| P0 | 环境初始化 | 官方题面+规则 | 工作目录骨架、`config/contest.json` | 题面/规则已落盘，环境可跑 |
| P1 | 读题与拆解 | 题面 | 约束清单、题型判定、选题结论 | 题意无歧义、主原型已定 |
| P2 | 建模 | 约束清单 | 假设≥3条、模型链、目标函数 | 基线模型跑通 |
| P3 | 求解 | 模型链 | 代码、结果、图、验证记录；条件触发的策略选择记录 | 结果可复现且有≥1种验证；有候选改进时用户已裁决 |
| P4 | 论文初稿 | 结果 | 摘要/正文/结论初稿 | 章节齐全、证据链闭合；有官方页数限制时不超限 |
| P5 | 打磨审校 | 初稿 | 终稿、封皮后匿名化、引用合规 | audit 脚本 PASS |
| P6 | 提交蒸馏 | 终稿 | 提交包、AI 披露、赛后复盘 | 提交审计 PASS |

详细契约见 `phases.md`；每阶段的检查命令见 `docs/PHASE_GATES.md`。

## 3. 三条并行流

比赛同时跑三条线，不要串行：

1. **求解线**：读题→建模→编码→结果（主程/代码手）。
2. **论文线**：边求解边记，结果一出就填章节，不要等到最后一夜写。
3. **验证线**：每出一个结果立刻想"怎么证明它对"，误差/对比/灵敏度随求解同步产出。

## 4. 常见崩盘点（按发生概率）

- **选题反复**：D1 中午前不定题，全天报废。见 `track-selection.md`。
- **没有 baseline**：D1 夜跑不通第一问，D2 写作无米下锅。
- **结果与论文数字打架**：摘要/正文/附录三套数字。见 `polishing.md` 数字一致性检查。
- **漏封皮 / 封皮后泄露身份 / 漏 AI 披露**：提交前才发现，直接违规。见 `submission.md`。
- **验证缺失**：只报结果不给对比，按官方"结果正确性"标准扣分。见 `validation.md`。

## 5. 边界

- 本模块只给时间地图，不替你做建模决策；建模走 `solving.md`，选题走 `track-selection.md`。
- 72h 是经验值，短于/长于当届窗口时按比例压缩/延长，门禁不变。
- 不承诺获奖，只保证流程不塌。
