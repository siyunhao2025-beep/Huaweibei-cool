# modules/polishing.md · 打磨审校

> **目标**：初稿到终稿的最后一公里——语言、格式、引用、数字一致性四件事查干净，跑 audit 脚本。对应 P5。

## 1. 语言润色

- 去 AI 味：按 `deai-writing.md` 六层诊断删空句、补具体。
- 学术规范：术语统一（全文同一个模型只叫一个名）、符号一致。
- 错别字、的/地/得、句子残缺。

## 2. 格式审校

- [ ] 字体字号：题目三号黑体、一级标题四号黑体、正文小四宋体、单倍行距；排版文本中的英文、阿拉伯数字和西文标点为 Times New Roman（Overleaf 缺字时 TeX Gyre Termes 回退），公式和代码使用各自专用字体。
- [ ] 无页眉。
- [ ] 页码从摘要页连续、页脚中部。
- [ ] 2026 正式 PDF 的物理第 1 页是官方封皮（逻辑第 0 页，不显示页码），物理第 2 页摘要从页码 1 开始；封皮之外全部匿名。
- [ ] 参考文献与附录分别另起一页：LaTeX 两处均由 `\clearpage` 清空浮动体后分页，Word 相应标题启用“段前分页”；没有人为插入空白页。
- [ ] 计算型论文的附录含代码式伪代码：输入审计、随机种子/冻结配置、数据或求解边界、真实核心算法、独立检验和导出齐全；逐步映射实际脚本/函数与结果文件，无空函数、占位符、未运行模块、绝对路径或身份信息。完整源码留在复现包。
- [ ] 每个“问题一/第 1 问”等一级问题标题后，在首个小标题、公式或图表前都有实质导读：回溯本问目标与真实前问接口，概括方法顺序，定位结果交付；不是题面复读或“本节将分析并得到结果”的空话。
- [ ] 每问内部顺序可顺读为“口径/输入 → 方法 → 结果 → 验证 → 结论/传递”；没有尚未定义的概念提前出现，也没有先报结论、后补评价口径。
- [ ] 图号/表号连续，与正文引用一致；公式编号连续（式 2.3 这种）。
- [ ] Figure 与 Table 均登记在视觉计划中并回链真实结果；用户锁定的顶层 Figure 总数、visual plan 与最终 LaTeX 三者完全一致；图负责趋势/结构，表负责精确查值，无同问题同证据的重复展示。
- [ ] 逐图核对正文详解：每张 Figure 都有图前定位、图注解码、具体证据读数、原因/机制、对本问或模型选择的含义、边界/异常/转折；复合图覆盖关键面板，流程图解释模块与箭头。只复述结果或把相关性写成因果均不得通过。
- [ ] 若 F01 是中文复杂多问总图：S1/S4 的 `visible_text_contract` 已锁中文自然语言与技术 token；S5 后没有伪造 S6。若做过用户明确授权的 consumer-side 本地化，原 S5 候选、本地化源图、标签账本、提示词和各层哈希均保留。可编辑矢量文字的宏观分区/节点/微标签分别 ≥11/10/9 pt；生成式 PNG 不虚报 pt，按最终插宽核对物理墨迹高度分别 ≥3.0/2.5/2.0 mm，图例 ≥2.2 mm。乱码、未登记英文自然语言、文字碰撞、箭头遮挡、边界溢出、裁切和语义错配均为 0；已运行 `scripts/audit_framework_figure.py`，确认 `main.tex` 的真实图片调用精确指向该图，并在哈希绑定的编译 PDF 指定物理页完成位图像素哈希或矢量区域渲染核验及逐字目检。
- [ ] 三线表、横轴带单位、图例齐全；全文颜色语义一致，关键差异同时有线型/点型/纹理等冗余编码。
- [ ] 摘要篇幅一般不超过两页，且不为凑页注水。
- [ ] 摘要仅对主要模型、决定性数值及核心结论/创新点使用粗体；数值与单位同时加粗，普通数字和整句未机械加粗。
- [ ] 已区分官方页数规则与用户篇幅裁决：官方目前无正文/全文上限；Figure 锁定后用户已选择具体总页数或“证据充分即可”。与裁决不一致时先解释证据差额，未靠套话、重复图表或版式膨胀修复。
- 跑 `scripts/audit_tex.py` 或 `audit_docx.py`（看你用 TeX 还是 Word）。

## 3. 引用审校

- [ ] 正文 [1][3] 方括号编号与参考文献一一对应。
- [ ] 参考文献按正文引用次序列出。
- [ ] 书籍带出版地/出版社/页码/年；期刊带卷期/页码/年；网上资源带网址+访问时间。
- [ ] 引用的程序注明来源。
- [ ] 仅当 AI 输出作为模型/公式来源进入论文时，按 2026 规定列明工具、版本/型号、机构和发布日期；普通 AI 使用按对应场景做标注。

## 4. 数字一致性检查（最容易翻车）

建一张核心数字表，逐格核：

| 问题 | 指标 | 值 | 来源文件 | 摘要? | 正文? | 附录? |
|---|---|---|---|---|---|---|

- [ ] 摘要里的每个数字，正文有同样的值。
- [ ] 正文结果与附录结果文件同源。
- [ ] 误差/降幅/利用率无"摘要 38.7%、正文 39%"这种打架。
- 数字打架→回 `evidence-ledger.md` 查真值，不手工凑。

## 5.5 优秀论文自检表·终审闭环（100% 勾选）

> 终审 = 论文写完后的**全量复查**，不是抽样。流程：

1. **从头全量复查一遍**：按章节顺序，对照 `assets/checklists/优秀论文自检表.md` 逐条过（写作阶段边写边勾过一遍，此处再全量复勾一遍）。
2. **运行机检脚本**：`python scripts/paper_checklist.py` 对论文产出自检报告，得到机检 ❌ 项。
3. **任何 ❌ 必须二选一**：① 修复到过；② 显式标注"不适用/未做到 + 原因"，不得静默跳过。
4. **人工条目（☐）必须全部裁决**：用 `--mark` 逐条裁决（做到 ✅ / 不适用 / 未做到+原因），裁决写入 sidecar（`paper_checklist_decisions.json`），**不允许留未裁决项**。
5. **最终产出 100% 闭环的《论文自检表_已勾选.md》**：做到的打 ✅，未做到的显式标注+原因+用户确认记录；整张表无未裁决项、无未解释 ❌。

> 该文件是 P6 提交门禁的硬性产物（见 `submission.md`、`docs/PHASE_GATES.md`）：机检 0 ❌ + 人工条目全裁决 + 已勾选自检表落盘，三者齐备才放行提交。

## 6. 终稿前最后一遍

- [ ] 无 TODO/无占位符/无"待补"。
- [ ] 封皮之外无身份标志（学校/姓名/队号）。
- [ ] 所有图能正常打开、不糊；所有表能在正常缩放下读清，图表均有独立信息增量。
- [ ] 从图1到最后一张图逐张朗读其前后正文：删除“如图所示+结果”式空解说，确认评委不看代码也能回答“怎么看、为什么、意味着什么、哪里失效”。
- [ ] PDF 导出无乱码、无缺图。
- [ ] 附录伪代码逐行可读、未被裁切或挤成一段；代码标题和正文映射一致，读者能由伪代码定位到复现包中的实际入口与产物。

终稿不是只“看一遍”：固定完成三轮互补检查。第一轮跑源码与自动化审计；第二轮用 XeLaTeX 双遍编译并逐页看渲染图；第三轮从实际 Overleaf/提交压缩包解压后重新编译，复核页码、匿名性、字体、缺图和溢出。

## 7. 常见错误

- 只顾内容忘了格式，摘要冗长而超过“通常不超过两页”的官方建议。
- 数字三处不一致，评委一眼看出。
- 改了正文忘了改摘要（或反之）。
- 引用了图但图文件路径坏，编译出来空图。
- 图后只重复“上升/下降/更优”，没有解释原因、模型含义和适用边界。
- 编号问题标题后立即进入公式、图表或二级标题，读者不知道本问要解决什么、为何采用该路线、最后交付什么。
- 附录只放 `import`、空函数或通用六步模板，却没有本题脚本、数据隔离、测试冻结和结果导出映射。
