# modules/deai-writing.md · 反模板 / 反 AI 味写作

> **目标**：把竞赛论文里"一眼 AI 味"的句子改成有真材实料的表达。改编自通用去 AI 味方法论（六层诊断），落到竞赛论文体裁；来源记录见 `docs/UPSTREAM.md`，不照抄原文。
> 2026 官方规定：AI 生成内容必须理解后用、用自己的话表述——本模块就是"用自己的话"的操作手册。

## 1. 为什么竞赛论文尤其怕 AI 味

评委一天看几十篇，"本文综合运用多种方法，取得良好效果，具有一定推广价值"这种句子一眼识破。AI 味直接拉低"文字表述清晰度"这一官方评审维度。

## 2. 竞赛论文常见 AI 味模式（六层诊断）

| 层 | 症状 | 竞赛论文例子 |
|---|---|---|
| 观点层 | 正确的废话、无取舍 | "该模型具有广泛的应用前景" |
| 结构层 | 机械三段式、每问等长 | 每问都"引言—模型—结果—小结"一模一样 |
| 表达层 | 空泛连接词、大词堆叠 | "综上所述/由此可见/具有重要的意义/提供了有力的支撑" |
| 素材层 | 无事实、假例子、泛化 | 无具体数字、无真实数据来源 |
| 叙事层 | 因果太顺、无失败无弯路 | 模型一次就成、从无试错 |
| 情感层 | 强行升华、结尾金句 | "为相关领域做出了重要贡献" |

## 3. 改写示例

| AI 味（删） | 改后（竞赛体） |
|---|---|
| 取得了良好的效果 | RMSE 0.07，较基线降 38.7% |
| 具有一定的推广价值 | 该方法在【同类数据规模/噪声水平】下适用，超出此范围需重标参数 |
| 本文综合运用多种方法 | 先做相关性分析，再用 X 建模、Y 残差修正 |
| 具有重要的理论意义 | （删，没意义就不写） |
| 该模型在多个领域得到广泛应用 | （无证据就删） |

## 4. 竞赛体裁的人感分寸

- **该工整处要工整**：公式推导、符号说明、参考文献本来就该正式，不要硬口语化。
- **该具体处要具体**：方法选择理由、误差数字、改进动机——这些是"人味"所在，靠具体不靠碎碎念。
- **允许写弯路**："先用 FNN 对 O3 偏差 17.14，改用 CEEMDAN 降噪降到 13.53"——这种"试错→改进"的因果链是真做过的痕迹，比一路顺风可信。
- **不编细节**：不要为了像真人编造对话、天气、无关故事；竞赛论文的真材实料是数字和动机。

## 5. 自检清单（终稿前逐段过）

- [ ] 删掉所有"具有重要意义/广泛应用/良好效果/提供有力支撑"类空句。
- [ ] 每个结论句后面有没有数字或文献支撑？没有就删或补。
- [ ] 有没有"为什么换模型"的真实动机句，而不是并列堆算法？
- [ ] 每问详略是否按难度自然分配，而非机械等长？
- [ ] 结尾有没有强行升华？有就删到事实为止。
- [ ] AI 生成段落是否已用自己的话重写、而非照贴？

## 6. 边界

- 去 AI 味 ≠ 口语化 ≠ 网感化；学术规范保留。
- 不为"自然"编造经历、数据、案例。
- 专业公式/参考文献不"人感化"，保持准确。
