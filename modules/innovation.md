# modules/innovation.md · 创新四象限

> **目标**：把你做的事提炼成评委认的"创新点"，而不是"我用了 XX 算法"。
> 本模块把深卡 `judge_high_score_reasons` / `reusable_patterns` 归纳成**创新四象限**，每象限给真实语料案例并标注 `paper_id`。
> 国一创新点不是"重大理论突破"，而是"在本题这个具体痛点上，做了别人没做的、可量化的改进"。

## 0. 一句话判断

> **观察到 X 现象 → 把 Y 换成 Z → 收益 N%**
> 三件套缺任何一件，都不是合格创新点（见 §4 伪创新清单）。

---

## 1. 创新四象限框架

| 象限 | 定义 | 评委眼中的加分点 |
|---|---|---|
| ① 方法组合 | 两种及以上方法的**有理由**组合，不是随便拼 | 说清"为什么拼、拼了解决什么痛点" |
| ② 数据处理 | 特征工程/数据清洗/缺失值/不平衡的创新 | 从数据里看出物理规律再动手 |
| ③ 验证严谨 | 多维验证/消融/鲁棒性/对标的创新 | 让评委"信"你做的是对的 |
| ④ 跨域迁移 | 把别的领域方法迁到本题 | 说清迁的是什么、为什么合适 |

> 一篇国一通常横跨 2–3 个象限；单一象限里堆 5 个方法不算创新。

---

## 2. 象限一：方法组合（有理由的组合）

**判据**：组合必须回答"为什么单方法不够"。

- **PCA + BP 神经网络**：PCA 把 11 个共线指标降到 3 个主成分，BP 再拟合非线性，与 MLR/逐步回归/最小二乘对比证明 BP 优。痛点：指标共线严重、关系非线性。来源：`2009_X_1048611A_6d0da813`。
- **PSO-GA 混合算法**：用 PSO-GA 混合求解 0-1 模糊规划选主要果蔬，预测环节再用 WPA 算子加权灰/BP/SVR 三模型。痛点：0-1 规划非凸、单预测模型偏置大。来源：`2014_D_D10357002_b5f65f8a`。
- **NSGA-II + 多岛遗传双层求解**：NSGA-II 求能耗-时间 Pareto 前沿，多岛遗传在前沿上优化时间分配。痛点：能耗与时间矛盾，需前沿而非单点。来源：`2014_D_K0032_810b1655`。
- **BiLSTM + MLP 跨站点融合**：BiLSTM 双向编码时序后接 MLP 融合站点个性/共性。痛点：单站 LSTM 跨站不通用。来源：`2021_B_B21102510017`。
- **XGBoost-MLP 两阶段 + 差分进化**：阶段一 XGBoost 同时面向活性与 ADMET 选变量，阶段二五个 MLP 并行，再把 MLP 当代理用 DE 全局搜变量取值。痛点：要找取值范围而非单点。来源：`2021_D_D21103000002`。
- **阻尼牛顿 + 逐维线性插值**：逐维插值避免整体平均误差，阻尼牛顿替代标准牛顿防发散，解 8 方程 8 未知量。痛点：标准牛顿发散、整体平均误差大。来源：`2013_A_A6_1a357ae6`。

## 3. 象限二：数据处理（从数据里看出规律）

**判据**：预处理不是"标准化一下"，而是**从数据诊断出问题再动手**。

- **环形变量伪独热码**：风向是环形变量，普通独热破坏连续性、普通归一化保留了不存在的大小关系，用伪独热码既消有序性又保连续。来源：`2021_B_B21105610069`。
- **理论距离 vs 测量距离误差清洗**：用理论距离与测量距离的误差直方图剔不良 2966 组数据，再 K-means 聚类筛代表。清洗有物理依据而非乱删。来源：`2021_E_E21103860006`。
- **分步冗余过滤 + 四法集成选变量**：方差过滤→类内/类间相关分步去冗余→Spearman/距离相关/随机森林/弹性网四法集成重要性，漏斗 729→341→137→20。来源：`2021_D_D21102800176`。
- **三种特征重要性互证**：内置/排列/SHAP 三种重要性交叉排序选 20 变量，再配 WOE/IV + 过采样处理不平衡。来源：`2021_D_D21104860088`。
- **极不平衡数据欠采样分层**：特大雨仅 92 条占 0.0025%，正视不平衡并按类别分层欠采样。来源：`2024_D_D24104460003`。
- **异常数据先修复再建模**：B 样条插值修复异常数据后再喂 SVM 识别意图。来源：`2015_A_A11075030_fcfb199e`。

## 4. 象限三：验证严谨（让评委信服）

**判据**：验证本身也能成为亮点——对标、消融、统计检验、双轨互验。

- **自研算法对标准库验证**：自研实时雨流计数 RRF 与 MATLAB 自带 rainflow 函数对 87 号风机 100 s 载荷谱做幅值/均值对比，完全重合。来源：`2024_A_A24102940057`。
- **消融证明模块必要性**：删去 RNCFD 的"暂时损伤项"后，第 99–100 s 指标突变、大扰动时刻误判，反证该模块必要。来源：`2024_A_A24102940057`。
- **统计检验替代看图说话**：设 0.05 显著性，用 Tukey 与 Levene 检验量化健康/PD 模型下 TH 神经元的水平与方差差异（p<0.05）。来源：`2021_C_C21104240047`。
- **精确解验证启发式**：小规模用 Gurobi 求 0-1 整数规划精确解，与启发式结果互验（A 组 206 班全满足且与最优一致）。来源：`2021_F_F21102480018`。
- **加噪鲁棒性测试**：测试集 + 加噪测试集双重验证，Bi-LSTM 无噪 R²=0.998、加噪仍 0.9952。来源：`2024_C_C24104220149`。
- **三守恒 + 多算法对比**：非齐次泊松仿真用能量/角动量守恒验证，并对 MC 削减/拒绝采样/Ogata thinning 三法横向对比（拒绝采样 R²=0.9946 最优）。来源：`2024_F_F24103360083`。

## 5. 象限四：跨域迁移（把别的领域方法搬过来）

**判据**：说清"迁的是什么、为什么和本题同构"。

- **生态学 Lotka-Volterra → 大气化学耦合**：把种间竞争微分方程迁移到 O3/NO2 耦合修正，刻画二者"争夺"关系，相对误差降到 3.79%/2.27%。来源：`2021_B_B21106990088`。
- **小样本元学习原型网络 → ADMET 分类**：ADMET 类别不平衡且样本少，引入原型网络小样本学习 + Borderline-SMOTE。来源：`2021_D_D21102800176`。
- **微分博弈界栅 + 分布式拍卖 → 无人机集群对抗**：从定性微分博弈界栅到定量生存博弈，多对多用 CBAA 分布式一致性拍卖做任务分配。来源：`2020_D_D20102690110`。
- **因果推断 SCM/传递熵 → 降水临近预报**：用多元传递熵做因果发现、结构因果模型（SCM）给确定性方程，替代黑箱 ConvLSTM。来源：`2023_F_F23910020096`。
- **排队论 → 拦截时序**：把舰艇拦截"准备 7 s、一舰一次一批"的时序抽象为排队论排拦截顺序，得最大抗饱和批数。来源：`2014_A_A10288020_5ab07000`。
- **传染病 SIR 模型 → 暴恐蔓延预测**：把暴恐事件蔓延类比传染病 SIR 建模，再叠加 RBF 时序预测 2018 态势。来源：`2018_C_C18900450036`。
- **储备池计算 ESN / 分层贝叶斯 → 气候预测**：鲁棒回声状态网络做非平稳温度预测，分层贝叶斯时空模型统一"全球变暖 vs 局地极寒"。来源：`2019_E_E19102540248`。

## 6. 伪创新识别清单（别写）

- [ ] "使用了 XX 算法"本身不是创新点——算法是工具，替换/组合/修正才是。
- [ ] 三个经典算法拼起来，却说不清为什么拼、解决了什么痛点（裸拼接）。
- [ ] 创新点无量化收益——"提高了精度/增强了鲁棒性"是废话。
- [ ] 把标准方法改个名字当新方法（"本文提出改进型 XX"但没说改了哪、为什么改）。
- [ ] 把参数调优说成创新（网格搜出来的最优超参不是创新，是调参）。
- [ ] 跨域迁移却说不清迁的是什么、为什么和本题同构。
- [ ] "首次提出/首创/国际领先"但查不到任何依据——评委见过的太多。
- [ ] 创新点和正文做法对不上（说用了 A，正文全是 B）。
- [ ] 把预处理/数据清洗做得对就吹成"重大创新"——它是象限二的本分，写清细节即可，不必拔高。

## 7. 创新点提炼流程（四步）

1. **从方法链找差异**：对照 `per_question_method_chain` 的 baseline→main_model，你在哪一步换了/加了/改了？差异点就是候选创新。
2. **与 baseline 对比**：这个差异带来多少量化变化？（降幅/误差/时间/精度）没有数字就回去补实验。
3. **用证据支撑**：差异是否有消融/对标/统计检验佐证？（对接 `validation.md`）
4. **精炼成 1–3 条表述**：每条套三件套——"观察到【X】→ 把【Y】换成【Z】→ 收益【N%】"。

> 例子：观察"分块矩阵强相关"→ 把"逐块独立求解"换成"上块解作下块热启动"→ 迭代仅 2~3 次（`2021_A_A21102910019`）。

## 8. 2024 高分新范式

> 物理机理打底 + ML 学残差 + 消融/对标。

- 纯遗传/纯熵权/纯 ARIMA 单独使用已降温；加分的是"机理方程显式建模 + 数据模型补残差 + 对标本库/标准函数验证"。
- 代表：`2024_A_A24102940057`（雨流机理+RL+对 rainflow 对标）、`2022_E_E22103350038`（Woodward 机理 + LSTM-FC）、`2024_C_C24103860012`（IGSE 物理先验做模型堆叠）。

## 9. 边界

- 创新点从真实做法来，不硬编"首次/首创"。
- 小改进也是创新（降复杂度、改预处理、加消融），不必非得重大理论突破。
- 不夸大；评委对包装很敏感。案例数字均为来源论文真实结果，引用时核对。
