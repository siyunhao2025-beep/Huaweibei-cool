# 2025 年 C 题：围岩裂隙精准识别与三维模型重构

- **year**: 2025
- **track**: C
- **证据等级**: **C（商业思路，无获奖论文简卡）**

## 题面主题与任务拆解

钻孔成像（Borehole Imaging）围岩裂隙识别与三维重构。
- 第 1 问：钻孔展开图像素级二分类分割（U-Net + BCE+Dice）。
- 第 2 问：正弦裂隙自动聚类（CCA）+ 正弦参数 L-M 拟合。
- 第 3 问：轮廓骨架化（Zhang-Suen）+ JRC 粗糙度计算。
- 第 4 问：多钻孔三维连通 + 补充钻孔 p-center 选址。

## 数据模态与规模

- 钻孔展开图（图像）+ 多钻孔坐标/方位。

## 官方硬约束/提交格式

- 裂隙产状几何一致性；JRC 标定。

## 题型原型映射

- **classification-cv（主）**：U-Net 分割、CCA、骨架化。
- **optimization（辅）**：p-center 选址。
- **mechanism（辅）**：裂隙几何产状。

## 方法谱系

- U-Net+BCE+Dice、CCA、L-M 曲线拟合、Zhang-Suen 骨架、JRC、p-center。

## 推荐路线与备选路线

- 主流：U-Net 分割 → 几何拟合 → 三维连通建模。
