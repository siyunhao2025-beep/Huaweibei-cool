# 华为杯研赛赛道档案（2022–2025）

> **重要红线：赛道字母按届重置、含义不跨届固定。** A/B/C/D/E/F 只是当年题目的编号，不代表"A=优化、B=评价"这种固定含义。
> 例：2022 A 是雷达信号、2023 A 是 WLAN 信道、2024 A 是风电场功率分配——字母相同，主题完全不同。
> 因此本目录**按年建档**（每题一份），并在 `track-selection-stats.md` 做**按原型跨届聚类**，严禁把"某字母=某题型"当定律。

## 证据等级说明

- **A 级**：有获奖论文深卡支持（逐问方法链+精确页码）。
- **B 级**：有获奖论文简卡支持（models_and_algorithms 字段）。
- **C 级**：仅商业/自媒体思路解析或成品论文，低于官方获奖论文。

2022–2024 年每题有 4–10 篇获奖论文简卡（B 级），其中部分有深卡（A 级）；2025 年无获奖论文简卡，全部为 C 级商业思路。

## 文件结构

- `2022/A.md`…`F.md`：2022 届六题。
- `2023/A.md`…`F.md`：2023 届六题（A/B 商业思路缺失，题面从获奖论文推断）。
- `2024/A.md`…`F.md`：2024 届六题（每题 4 篇获奖论文，样本量小）。
- `2025/A.md`…`F.md`：2025 届六题（全部 C 级）。
- `track-selection-stats.md`：跨届选题难度/数据量/方法趋势/获奖分布统计。

## 数据来源优先级

获奖论文深卡 > 获奖论文简卡 > 赛题解析思路资料 > 商业成品论文（标 C）。
